**GSD installs for Kiro with `--kiro`** — skills land in `.kiro/skills/gsd-*/SKILL.md` (invocable as `/gsd-<name>` and auto-activated by description) and custom agents in `.kiro/agents/gsd-*.md` with Claude tool grants mapped to Kiro tool tags; the global install honours `KIRO_HOME`. A Kiro install lives beside a Claude Code install in the same project and shares its `.planning/` state.
